## Verdict

**Ready for user acceptance.** M15 criteria V01 and V02 are **met**. Epic #1008 stays **open** until the user accepts it.

`mitbih_fetch` downloads `100.hea`, `100.dat`, and `100.atr` from PhysioNet (ODC-By 1.0, DOI 10.13026/C2F305), checks the byte size and sha256 in `demos/mitbih/manifest.json`, and stores them under `downloads/mitbih/`. `demos/mitbih/load_record100.m` reads format 212 into millivolts at 360 Hz. The three files are not committed.

Citation: G. B. Moody and R. G. Mark, IEEE Eng. Med. Biol. Mag. 20(3):45–50, 2001. A. L. Goldberger et al., Circulation 101(23):e215–e220, 2000.

The `downloads/` rule already ignores the cache. `downloads/mitbih/` in `.gitignore` restates the M15 policy.

A separate urllib fetch into an empty directory (`mitbih.fetch(Path('/tmp/mitbih-urllib'))`, cache not reused) checked the same three sizes and sha256, then `load_record` printed:

```text
fetch /tmp/mitbih-urllib
100.hea ok 143
100.dat ok 1950000
100.atr ok 4558
fs 360.0 n 650000 mv0 -0.145 anns 2274 aux0 (N s0 18
```

`mv0 = -0.145` is `(995 - 1024) / 200` from the header initial value, gain, and baseline. V5's first sample is -0.065, `(1011 - 1024) / 200`. Both channels' 16-bit checksums match the header (the loader raises otherwise). The 2274 annotations and the `(N` rhythm label are a measured parse of `.atr`, not a diagnostic golden. `ann_sample` in MATLAB is 1-based (file sample 18 is index 19).
