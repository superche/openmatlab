## Verdict

**Ready for user acceptance.** M16 criterion V03 is **met**. Epic #1021 stays **open** until the user accepts it. Epics #1020 and #1022–#1025 stay open. This epic does not start I-E3.

`graythresh` / `imbinarize` apply a global Otsu threshold. On the cached stage1_test FOV the level is `22/255`. `bwareaopen` with `P = 50` and 8-connectivity removes components smaller than 50 pixels. A 1-by-2 `tiledlayout` shows the raw FOV and the mask.

Citation: J. C. Caicedo et al., Nature Methods 16:1247–1253, 2019. doi:10.1038/s41592-019-0612-7. BBBC038v1. CC0 1.0. The zip and the PNG are not committed.
