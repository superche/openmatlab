# MIT-BIH record 100

Runtime download of PhysioNet record 100 only. The `.hea`, `.dat` and `.atr` files are cached under `downloads/mitbih/` and are not part of this repository.

```bash
openmatlab -e "run('demos/mitbih/story_record100.m')"
```
